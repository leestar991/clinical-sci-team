```markdown

### 基本信息
- **文件类型**：[PDF海报 / Markdown / 数据表]
- **对应资产/化合物**：[名称 + 编号/代号]
- **Modality**：[小分子/ADC/双抗/分子胶/PROTAC等，注明靶点和作用状态]
- **主题关键词**：[5-8个，含化合物名/靶点/突变/机制/适应症]
- **研究阶段**：[临床前/IND申请/I期/II期/已批准，有则引用NCT号]
- **证据编号前缀**：[D-[文件编号]-XX]

### 核心内容提炼
- **靶点与机制**：[结合位点、作用机制，详述分子层面事件；若有结构数据则描述构象变化] [D-xx]
- **关键量化数据**：[ORR/PFS/OS/DLT/CR率/IC50/EC50/KD/TGI/PK参数，逐条列出，附测定条件（细胞系/突变类型/动物模型），有则列出，标注 [D-xx]；无则写"文档未披露" [G-xx]]
- **创新点/差异化主张**：[与已知药物/路线的机制差异化，文档中明确宣称的，1-3条，不得编造对比数据] [D-xx]
- **适应症与患者人群**：[靶向突变类型、疾病背景、细胞系/PDX/CDX/患者样本]

### 竞争相关信息
- **与已上市/在研药物的对比**：[仅列文档中直接出现的数值对比，标注 [D-xx]；若无系统比较，写"文档未提供头对头比较" [G-xx]]
- **联合用药线索**：[文档提及的每个联合方案，注明联合伙伴机制 + 具体模型名称 + 协同数据/统计显著性；无则写"N/A"]
- **耐药机制线索**：[区分：①文档明确报告的耐药机制；②暗示的线索；③机制推断（标注"推断"）；无则写"N/A"]

### 可引用内容
- **核心结论**（2-5条，直接引用原文数据或结论，附证据编号）：

  2. [结论2] [D-xx]
  3. [结论3，如有]
- **数据可靠性**：[已验证（已发表/注册临床） / ⚠️ 未验证（摘要/海报）]

### 证据编号清单
| 编号 | 类型 | 内容摘要 | 文档位置 |
|---|---|---|---|
（每个证据点一行；类型：文献来源/机制/结构/量化-结合/量化-细胞/量化-PK/量化-体内/联合/竞品/耐药/阶段/方法学/推断）
```
