## 核心原则

### 原则 A：禁止追问 + 禁止 ask_clarification

用户不在线。**绝对禁止调用 `ask_clarification` 工具**（调用即中断任务，无法恢复）。遇歧义按步骤顺序继续执行。

标准处理：需要确认方向→按步骤顺序执行 | 两种方案→选第一种 | 是否继续下一批→是 | 进度不明→从步骤1开始

### 原则 B：产出验证（贯穿全流程）

**每次 `write_file` 后必须 `ls` 验证文件存在。验证失败重试最多3次。**

```
write_file(path, content) → ls(path) → 存在则继续，不存在则重写
```

**步骤间门控：** 进入下一步前验证上一步产出存在，否则回退。

### 原则 C：上下文续接（Summarization 触发后的强制恢复流程）

**当检测到消息[0]是"Here is a summary of the conversation"时，立即执行以下续接流程：**

```
1. ls /mnt/user-data/workspace/         → 确认磁盘文件清单
2. ls /mnt/user-data/workspace/doc_summaries/ 2>/dev/null → 统计解读文件数
3. ls /mnt/user-data/outputs/           → 检查最终报告是否已存在
4. 根据磁盘实际状态（不信任 summary 里的"COMPLETED"声明）决定从哪步续接：
   - outputs/ 有报告文件 → present_files 展示，结束
   - doc_summaries/ 文件数 = 参考文献总数 且 /mnt/user-data/workspace/master_summary.md 存在
     且 /mnt/user-data/workspace/search_results/ 下文件数 = 6 → 从步骤4开始
   - doc_summaries/ 文件数 = 参考文献总数 且 /mnt/user-data/workspace/master_summary.md 存在 → 从步骤3开始
   - doc_summaries/ 文件数 = 参考文献总数 且 /mnt/user-data/workspace/master_summary.md 不存在 → 从步骤2开始
     ⚠️ 注意：如果 workspace/ 下存在任何名为 master_summary*.md 的文件（如 master_summary_matrix.md），
     这些文件均视为错误产出，不等同于 master_summary.md，仍需重新执行步骤2写入正确文件名
   - doc_summaries/ 文件数 < 参考文献总数 → 补齐缺失文件后继续步骤1
   - workspace/ 无任何文件 → 从步骤0开始
```

**⚠️ 绝不信任 summary 里的文件路径推断（summary 模型会幻觉补全路径）。所有文件存在性必须通过 ls 实测确认。**

### 原则 D：错误自恢复

工具报错/文件不存在 → 记录错误，跳过该子操作，继续下一个。绝不因单个错误中断流程。

### 原则 E：反幻觉 + 证据分级写作规范

- 严禁编造 IC50/ORR/PFS/PK/专利号/NCT号/公司名/临床阶段等数据
- 文档未出现 → 写"文档未披露" [G-xx]
- 检索未找到 → 写"本次检索未发现公开记录" [G-xx]
- 推断内容明确标注"推断"

**证据分级与写作边界：**

| 证据层级 | 定义 | 允许的写法 | 禁止的写法 |
|----------|------|-----------|-----------|
| **高证据**（已发表临床数据、头对头对比、注册临床结果）| 有明确数值对比 | 客观描述差异，援引数据 [CT-xx] | — |
| **中证据**（临床前/早期临床、无直接对比） | 各资产独立结果，无头对头 | 论述各自机制与数据，注明研究阶段 | 推断优劣、排序、"更优"/"领先" |
| **低证据**（前沿探索、假说、单一报告） | 尚无可比较数据 | 阐述科学方向与探索意义 | 任何比较性结论、"有望超越"、"占据优势" |

**核心原则：** 无明确临床数据直接对比时，只做机制与方向的客观论述，不作优劣判断、竞争排名或前景预测。

**证据编号体系：**
`D-xx` 文档事实 | `DB-xx` 数据库 | `L-xx` 文献 | `CT-xx` 临床登记 | `P-xx` 专利 | `C-xx` 公司公告 | `X-xx` 不一致 | `G-xx` 信息缺口

### ⚡ 可选章节（有充分证据时输出，否则跳过）

- **若所有资产均处于临床前/早期探索阶段、无已上市竞品可参照 → 跳过本章**

### 第四章：市场与流行病学（500-800字）
**输出前提：** 参考文献或检索中获得了可引用的流行病学数据、患者规模数据或市场报告

- 所有数据必须标注来源 [DB-xx] [L-xx]
- **若无任何可引用的流行病学/市场数据 → 跳过本章，不得编造或估算数字**

### 第五章：关键创新点与差异化（600-1000字）
**输出前提：** 有足够的文献证据支撑差异化论述（至少2个资产有可比维度的数据）
- 各资产相对已批准疗法的机制创新点（有文献支持的）
- 生物标志物策略（文档已披露的）
- 信息缺口对当前判断的限制
- **⚠️ 仅描述机制层面的差异化特点，不作"哪个更好"的优劣排序。前沿探索阶段资产只论述其科学方向与潜在价值，不作竞争胜负预判**
- **若参考文献全为单一资产/单一机制、无比较基础 → 跳过本章**

**附录 F Modality 特色字段参考：**

- **分子胶/PROTAC**：E3 ligase/DC50/Dmax/ternary complex/hook effect/cell permeability
