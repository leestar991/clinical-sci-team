# 内置同义词对照表

填写 `同义词` 时**至少**覆盖下表已知易漏项。`eligibility-judgment` 的
`uncertain_recheck.py`（`BUILTIN_SCALE_SYNONYMS`）内置同一张表作为确定性反查兜底。

## 类别 → 具体药名（桥接，最易漏）

标准写**类别**（"仍需全身性药物治疗"），病历写**药名**（"地塞米松"）。不桥接，下游就永远对不上，
判定侧会写出事实错误的缺失断言。

| 类别 | 具体药名 |
|------|----------|
| 全身性糖皮质激素 | `糖皮质激素` / `皮质激素` / `皮质类固醇` / `地塞米松` / `泼尼松` / `泼尼松龙` / `甲泼尼龙` / `氢化可的松` / `倍他米松` / `曲安西龙` / `可的松` |
| 紫杉类 | `紫杉类` / `紫衫类` / `多西他赛` / `紫杉醇` / `白蛋白紫杉醇` / `卡巴他赛` |
| 新型内分泌治疗 | `阿比特龙` / `恩扎卢胺` / `氘恩扎如胺` / `阿帕他胺` / `达罗他胺` / `瑞维鲁胺` |
| 免疫抑制剂 | `环孢素` / `他克莫司` / `硫唑嘌呤` / `甲氨蝶呤` / `霉酚酸酯` / `环磷酰胺` |
| 减毒活疫苗 | `麻疹疫苗` / `水痘疫苗` / `黄热` / `卡介苗` / `脊灰减毒` |

⛔ **三处必须一致**（有一处漏就是一个盲区）：

1. 本表；
2. `eligibility-judgment/scripts/uncertain_recheck.py` 的 `BUILTIN_SCALE_SYNONYMS`；
3. `eligibility-judgment/scripts/check_reason_alignment.py` 的 `_CLASS_TO_DRUGS`。

由 `tests/skills/test_drug_class_synonym_consistency.py` 机械核对。
